This repository contains MATLAB implementations of various Numerical Optimization and Numerical Methods algorithms commonly used in engineering, mathematics, and scientific computing.

The programs are written for learning and practice purposes with simple and understandable code structure.

🔹 Root Finding Methods
Newton Raphson Method
Bisection Method
Secant Method
False Position Method
🔹 Numerical Integration
Trapezoidal Rule
Simpson’s 1/3 Rule
Simpson’s 3/8 Rule
🔹 Numerical Differentiation
Forward Difference Method
Backward Difference Method
Central Difference Method
🔹 Linear Algebra Methods
Gauss Elimination
Gauss Jordan Method
LU Decomposition
🔹 Interpolation Methods
Newton Forward Interpolation
Newton Backward Interpolation
Lagrange Interpolation

MATLAB
